## Cookie Slicer: ตัวติดตั้งตัวช่วย (ม็อด v1.1.0)

**โหลด `CookieSlicer-Setup.bat` ด้านล่าง → ดับเบิลคลิก → กด 1**
(ถ้าเคยลงแล้ว: กด 1 อีกรอบเพื่ออัปเดตตัวช่วยเป็น v1.1.0)

### ใหม่
- หน้าต่างใหม่ ตัวใหญ่ ธีมดำ-มิ้น: ประสิทธิภาพ / Shader / Version Slicer
- ชี้เมาส์ที่ตัวเลข มีคำอธิบายว่าคืออะไร และของเราเป็นยังไง
- ระดับ คืนค่าเดิม / สมดุล / ลื่น / ลื่นสุด หรือเปิดปิดทีละข้อ, บอกว่าจะลดอะไรได้ประมาณเท่าไหร่, วัด FPS ก่อน/หลัง
- **Shader จริง** (ต้องมีตัวช่วย v1.1.0): 8 สไตล์ + ปรับค่า 9 อย่าง, เช็คว่าเครื่องไหวไหม (วัด ms จริง), ปุ่มแนะนำให้เข้ากับคอม, เทียบก่อน/หลังในเกม
- ใช้หน่วยความจำการ์ดจอ ~11 MB ที่ 1080p ไม่กิน RAM เครื่อง

### ไฟล์
- `CookieSlicer-Setup.bat`: Windows (1 ลง/อัปเดต, 2 ถอนออก, 3 เช็ค)
- `cookieslicer-setup.sh`: Linux
