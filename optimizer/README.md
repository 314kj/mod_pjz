## มีอะไรบ้าง

Cookie Slicer มี 3 ส่วน:

| ส่วน | อยู่ที่ไหน | ผู้เล่นต้องทำอะไร |
|---|---|---|
| **ฝั่งเซิฟ** | เครื่องเซิฟ Cookie Cheetah | ไม่ต้องทำอะไร |
| **ม็อด Cookie Slicer** | Steam Workshop (โหลดเองตอนเข้าเซิฟ) | ไม่ต้องทำอะไร |
| **ตัวช่วย (Helper)** | เครื่องผู้เล่น | ลงเองถ้าอยากได้ (ไม่บังคับ) |

| | ไม่ลงตัวช่วย | ลงตัวช่วย |
|---|:---:|:---:|
| ปรับเกมให้ลื่น (คืนค่าเดิม / สมดุล / ลื่น / ลื่นสุด) | ✅ | ✅ |
| บอกว่าตั้งแล้วจะลดอะไรได้ประมาณเท่าไหร่ + วัด FPS ก่อน/หลัง | ✅ | ✅ |
| โทนภาพพื้นฐาน 4 แบบ + ความสว่าง | ✅ | ✅ |

| ดู RAM / CPU / เธรดหลัก / การ์ดจอ แบบสดๆ พร้อมคำอธิบาย | ❌ | ✅ |
| ให้เกมใช้ RAM เพิ่ม | ❌ | ✅ |
| ปุ่ม Cookie Slicer ที่หน้าเมนูหลัก | ❌ | ✅ |

## 1. ใช้ได้ทันที ไม่ต้องลงอะไร

1. เข้าเซิฟ Cookie Cheetah
2. กด **F8** (เปลี่ยนปุ่มได้ที่ Options > Mods > Cookie Slicer)
3. หน้า **ประสิทธิภาพ** → กด **ลื่น** (ปรับ 6 อย่างที่กินเครื่องแต่ตาแทบไม่เห็น ตัวละครหน้าตาเหมือนเดิม)
4. คอมอ่อน / โน้ตบุ๊ก → กด **ลื่นสุด** แล้วปิดเกมเปิดใหม่ 1 ครั้ง
5. ไม่ชอบ → กด **คืนค่าเดิม** ได้ตลอด (กลับเป็นค่าที่เราตั้งไว้เองก่อนหน้า)

ทั้งหมดนี้คือ**ตัวเลือกของเกมเอง** (เหมือนเข้าไปตั้งใน Options) ไม่แก้เซฟ ไม่แก้ไฟล์เกม

> ชี้เมาส์ที่ตัวเลขในหน้าต่าง จะมีคำอธิบายว่าคืออะไร สำคัญยังไง และเครื่องเราตอนนี้เป็นยังไง

## 2. ลงตัวช่วย (Windows)

ใช้เวลาประมาณ 2 นาที

1. **ปิดเกมให้หมด** (กดออกจากเกม ไม่ใช่แค่กลับหน้าเมนู)
2. โหลด **[CookieSlicer-Setup.bat](https://github.com/314kj/mod_pjz/releases/download/cookie-slicer-setup/CookieSlicer-Setup.bat)**
3. ดับเบิลคลิกไฟล์ที่โหลดมา
   - ถ้าขึ้นจอฟ้า *"Windows protected your PC"* → กด **More info** → **Run anyway** (Windows เตือนทุกไฟล์ที่โหลดจากเน็ตและไม่มีลายเซ็นบริษัท)
4. กด **1** แล้วกด **Enter**
   - ตัวติดตั้งจะบอกเวอร์ชันตัวช่วยที่ลง (เช่น `Helper v1.4.0 installed` หรือ `updated v1.3.0 -> v1.4.0`)
5. ถามโหมด: กด **Enter** ได้เลย (ใช้ค่าที่แนะนำ)
   - **1 เต็ม**: ตัวเลข CPU / RAM, Shader, ตัวเร่ง และ RAM เกม (ปกติใช้อันนี้)
   - **2 เข้ากับ ZombieBuddy / Viewpoint**: ตั้งแค่ RAM เกม ไม่เปิดตัวช่วย (ดูหัวข้อถัดไป)
6. รอ Steam ปิดแล้วเปิดเองอัตโนมัติ (ประมาณ 1 นาที) จนขึ้นว่า **เสร็จ**
7. เปิด Project Zomboid → มุมขวาบนของหน้าเมนูหลักมีปุ่ม **Cookie Slicer** = ลงสำเร็จ

| ตัวติดตั้ง | ทำอะไร |
|---|---|
| กด **1** | ลง / อัปเดต (ม็อดอัปเดตบน Workshop เมื่อไหร่ ให้กด 1 อีกรอบ) |
| กด **2** | ถอนออก คืนทุกอย่างเป็นเหมือนเดิม |
| กด **3** | เช็คว่าลงครบไหม |

### ใช้คู่กับ ZombieBuddy / Viewpoint (มุมมองบุคคลที่ 1)

ZombieBuddy เป็นม็อด Java ที่แก้โค้ดเกมตอนโหลดเหมือนตัวช่วยของเรา ถ้าเครื่องมี ZombieBuddy ตัวติดตั้งจะเจอเองและแนะนำโหมด 2

1. ลง ZombieBuddy (และ Viewpoint) ให้เสร็จก่อน แล้วค่อยเปิดตัวติดตั้งของเรา
2. กด **1** แล้วตอนถามโหมด ลองกด **1 (เต็ม)** ก่อน
3. เปิดเกม ถ้าเข้าหน้าเมนูได้และ Viewpoint ใช้ได้ = จบ
4. ถ้าเกมเด้งปิดเอง หรือ Viewpoint ใช้ไม่ได้ → เปิดตัวติดตั้งใหม่ กด **1** แล้วเลือกโหมด **2**
5. ยังไม่ได้อีก → ส่ง `Zomboid\console.txt` และ `%TEMP%\CookieSlicer-setup.log` ให้แอดมินใน Discord

โหมด 2: หน้าต่าง Cookie Slicer ขึ้น `--` แทนตัวเลข CPU / RAM, ไม่มี Shader จริง และเปลี่ยน RAM เกมจากหน้าต่างไม่ได้ (เปลี่ยนโดยเปิดตัวติดตั้งแล้วกด 1 ใหม่) หน้าประสิทธิภาพของม็อดยังใช้ได้ปกติ
อยากกลับเป็นโหมดเต็ม: เปิดตัวติดตั้ง กด **1** เลือก **1**

> ต้อง Subscribe ม็อด Cookie Slicer บน Workshop ไว้ก่อน (ถ้าเคยเข้าเซิฟแล้ว มีอยู่แล้ว)
> โหลดตัวติดตั้งจาก**ลิงก์ในหน้านี้หรือใน Discord ของเซิฟเท่านั้น** ถ้ามีคนส่งไฟล์ชื่อเดียวกันมาจากที่อื่น อย่าเปิด

## 3. ใช้ Shader

1. เข้าเซิฟ → กด **F8** → หน้า **Shader**
2. ดูกล่อง **"ใช้ได้กับเครื่องนี้ไหม"** (เช็คครบตอนอยู่ในเกม)
   - 🟩 เขียวทุกข้อ = ใช้ได้เลย
   - 🟨 เหลือง = ใช้ได้ แต่ให้กด **แนะนำให้เข้ากับคอม**
   - 🟥 แดง = ยังใช้ไม่ได้ (อ่านเหตุผลในกล่อง) ระหว่างนี้ใช้โทนภาพพื้นฐานได้
3. เลือกสไตล์: ธรรมชาติ / ทองยามเย็น / ฟิล์มสมจริง / ไฟเรืองยามค่ำ / สีจัด / ภาพยนตร์ / เรโทร / มืดสมจริง
4. ปรับแถบได้ 9 อย่าง: ความแรง ความสว่าง คอนทราสต์ ความสด อุ่น/เย็น แสงเรือง ขอบจอมืด ความคม เม็ดฟิล์ม
5. กด **ดูเทียบก่อน / หลัง ในเกม** → หน้าต่างหลบไปซ้าย ฝั่งขวาเป็นเกมจริง: ซ้ายของเส้น = ก่อน, ขวาของเส้น = หลัง
6. ไม่อยากใช้ → เลือก **ธรรมชาติ** หรือปิดสวิตช์ **เปิด Shader**

- ใช้หน่วยความจำการ์ดจอประมาณ 11 MB ที่จอ 1080p (4K ประมาณ 44 MB) ไม่กิน RAM เครื่อง
- กินการ์ดจอเท่าไหร่ วัดจริงแล้วโชว์ในกล่อง (ms ต่อเฟรม) การ์ดจอแยกส่วนใหญ่ไม่ถึง 1 ms
- ตอนใส่แว่นมองกลางคืน Shader หยุดเอง ภาพเขียวของแว่นเป็นแบบที่เกมวาด
- หน้าต่าง UI ของเกมไม่โดน Shader (สีเมนูเหมือนเดิม)

## 5. ตัวติดตั้งทำอะไรกับเครื่องเรา / ข้อมูลของเรา

ตัวติดตั้งทำแค่นี้ และกด **2** เอาออกได้หมด:

- ก๊อปไฟล์ 2 ไฟล์ (ตัวช่วย `.jar` กับ `run.ps1`) จากม็อดบน Workshop ไปไว้ที่ `%LOCALAPPDATA%\CookieSlicer`
- ใส่ Launch Option ของ Project Zomboid ใน Steam ให้เกมเปิดผ่านตัวช่วย (ปิด Steam ก่อนแก้ และเก็บไฟล์ตั้งค่า Steam เดิมไว้เป็น backup)
- ใส่ม็อด Cookie Slicer ในรายการม็อดของหน้าเมนูหลัก (`Zomboid\mods\default.txt`)
- ตั้ง RAM ให้เกมให้พอดีกับเครื่อง (เฉพาะถ้าเดิมน้อยกว่าที่ควร ตั้งเองได้สูงสุด 12 GB อยากได้ 16 GB เลือกเองในหน้าต่าง)
- จำโหมดที่เลือก (`mode.txt` ในโฟลเดอร์เดียวกัน)
- เขียนบันทึกการทำงานไว้ที่ `%TEMP%\CookieSlicer-setup.log`

ตัวช่วยตอนเกมเปิดอยู่:

- **ไม่ส่งข้อมูลอะไรออกจากเครื่อง** ไม่ต่อเน็ต ตัวเลขทั้งหมดเขียนไว้ในเครื่องเราเอง (`Zomboid\Lua\CookieSlicer_*.txt`) ให้ม็อดอ่าน
- อ่าน: CPU / RAM ของเครื่องและของเกม, เธรดที่ทำงานหนักสุด, ชื่อการ์ดจอ, เวอร์ชัน OpenGL, หน่วยความจำการ์ดจอที่ว่าง
- ไม่แก้ไฟล์เกมในเครื่อง แก้การทำงานของเกม**เฉพาะตอนที่เกมเปิดอยู่ ในหน่วยความจำ** 1 จุด (จุดที่เกมวาดภาพโลกเสร็จ เพื่อวาด Shader ต่อ) ปิดเกม = หายไป
- ถ้าอะไรผิดพลาด Shader จะปิดตัวเองในรอบนั้น เกมเล่นต่อได้ตามปกติ

## ทำงานยังไง (ภาพรวม)

**ฝั่งเซิฟ (Cookie Slicer v4)**
ตอนผู้เล่นวิ่ง/ขับรถ เซิฟต้องโหลดแผนที่ใหม่ตลอด และทุกม็อดที่ผูกกับ "ช่องแผนที่โหลดเสร็จ" จะทำงานพร้อมกันในเฟรมเดียว ทำให้ tick ค้าง (คนในเซิฟรู้สึกว่าแลค)
ฝั่งเซิฟจะเลื่อนงานพวกนี้ไปทำทีละนิดในหลาย tick ถัดไป โดยมีงบเวลาต่อ tick และยังรับประกันว่างานของช่องนั้นเสร็จก่อนผู้เล่นจะได้รับข้อมูล / ก่อนเซฟ / ก่อนช่องถูกปลดออก
มีตัวเลขทุกนาทีใน log (tick ต่อนาที, tick ที่ช้าเกิน 1 วินาที ฯลฯ) และเปิด/ปิดได้โดยไม่ต้องรีสตาร์ท

**ม็อด Cookie Slicer (Lua)**
หน้าต่าง F8 / ปุ่มเมนูหลัก, การตั้งค่าเกมให้ลื่น, โทนภาพพื้นฐาน, คิวงานโหลดแผนที่ฝั่งผู้เล่น (Cookie Square Queue), เมนูคลิกขวาวัดความกว้างตัวหนังสือแต่ละบรรทัดครั้งเดียว (ม็อด v1.4.0), ตัวช่วย v1.4.0: ขับรถลื่น (ทำแมพชิ้นใหม่ไม่เกิน 4 ms ต่อเฟรม) และเลือกจำนวนซอมบี้ 3D (510 ค่าเกม / 300 / 200 / 150) ในหน้า Speed Slicer, ตัววัดเวลา Lua ของแต่ละม็อด (Cookie Profiler, เปิดเฉพาะตอนแอดมินสั่ง)

**ตัวช่วย (Java agent)**
เกมเปิดผ่าน Steam Launch Option ที่ตัวติดตั้งตั้งไว้ ตัวช่วยวัดตัวเลขเครื่องทุก 2 วินาที และวาด Shader เป็นอีกรอบหลังจากที่เกมวาดภาพโลกเสร็จ (หลัง shader ของเกมเอง ก่อนหน้าต่าง UI) ด้วยไฟล์ shader ของเรา (`CookieSlicer/…/media/shaders/cookie_post.*`)

## ทำไมไม่เหมาะเอาไปใช้ที่อื่นหรือดัดแปลง

Cookie Slicer ทำมาสำหรับเซิฟเราเซิฟเดียว ทดสอบและปรับกับเซิฟเราเท่านั้น เหตุผลที่ไม่ควรเอาไปใช้ที่อื่น:

1. **ผูกกับเวอร์ชันเกมแบบตรงตัว**
   ฝั่งเซิฟและตัวช่วยแก้การทำงานของเกมโดยหา "คำสั่งเรียก" ที่ตำแหน่งเฉพาะในโค้ดของ Project Zomboid build 42.22.2 ถ้าเกมเปลี่ยนเวอร์ชัน คำสั่งพวกนั้นอาจย้ายหรือหายไป ระบบจะปิดตัวเองเพื่อความปลอดภัย แต่ก็แปลว่า**เวอร์ชันอื่นอาจไม่ทำงานเลย**
2. **ผูกกับรายการม็อดของเซิฟเรา**
   การเลื่อนงานโหลดแผนที่ไปทำทีหลัง เปลี่ยน "จังหวะ" ที่ม็อดอื่นทำงาน เราเช็คแล้วว่าม็อดในเซิฟเราทำงานถูก (ตัวที่ต้องแก้ แก้ไว้ใน CookieServerPatch) แต่ม็อดที่เราไม่มี**อาจพังแบบเงียบๆ** เช่น ของไม่เกิด ข้อมูลในเซฟผิด
3. **ค่าต่างๆ จูนจากเซิฟเรา**
   งบเวลาต่อ tick, จำนวนงานต่อรอบ, ส่วนแบ่งงานที่ใช้คำนวณ "คาดว่าจะลดลง", เกณฑ์ลื่น/พอเล่น/หนัก ทั้งหมดมาจากการวัดบนเครื่องเซิฟและผู้เล่นของเรา ใช้ที่อื่นตัวเลขจะผิด
4. **เปลี่ยนการทำงานของเกมในระดับที่ลึก**
   ตัวช่วยแก้การทำงานของเกมในหน่วยความจำและแก้ Launch Option ของ Steam ในเครื่องผู้เล่น ถ้าดัดแปลงผิดนิดเดียว เกมอาจเปิดไม่ขึ้นหรือภาพเพี้ยน และ**คนที่ใช้ของที่ถูกดัดแปลงไม่มีทางรู้ว่าไฟล์ปลอดภัยไหม**
5. **ไม่มีการรับประกันว่าจะเหมือนเดิม**
   เราอัปเดตตามที่เซิฟต้องการ ไม่มีการรักษาความเข้ากันได้กับใคร อะไรที่ไปพึ่งโค้ดนี้อาจพังได้ทุกเมื่อโดยไม่แจ้ง และไม่มีซัพพอร์ตนอกเซิฟ Cookie Cheetah
6. **ข้อความและลิงก์ผูกกับเซิฟเรา**
   ภาษาไทย/อังกฤษในหน้าต่าง ลิงก์ Discord, Workshop ID และวิธีช่วยเหลือ ชี้มาที่เซิฟเราทั้งหมด

ถ้าคุณเป็นแอดมินเซิฟอื่นและสนใจแนวคิด ติดต่อทีม Cookie Cheetah ใน Discord ได้ แต่ห้ามนำโค้ด ไฟล์ หรือตัวติดตั้งไปใช้ ดัดแปลง หรืออัปโหลดซ้ำ

## English

> [!WARNING]
> **Made only for the Cookie Cheetah dedicated server.** Not a general mod, not meant to be used on other servers, modified or built upon.
> Parts of it change how the game itself works at points that depend on the exact game build (42.22.2), the server's mod list and settings measured on our machines. On another game version it may switch itself off or do nothing; with mods we do not run it may quietly break them (timing of map-load events changes). The player helper changes the game in memory and the Steam launch option, so a modified copy can stop the game from starting and nobody using it can tell whether it is safe. There is no compatibility promise and no support outside Cookie Cheetah. The code is public so our players can see what runs on their PC, not for reuse.

Cookie Slicer is the Cookie Cheetah server's own performance mod. In game press **F8**: *Performance* (levels Undo all / Balanced / Smooth / Max, one switch per setting, what to expect, FPS before / after, live PC numbers with explanations) and *Shader*.
The optional **Helper** adds a real screen shader (8 styles, sliders, "Fit my PC", before / after compare), live RAM / CPU / GPU numbers and more RAM for the game.

Install: close the game, run **[CookieSlicer-Setup.bat](https://github.com/314kj/mod_pjz/releases/download/cookie-slicer-setup/CookieSlicer-Setup.bat)**, press **1** (update: 1 again, remove: 2, check: 3). It shows the helper version it installed, then asks the mode: **1 Full** (default) or **2 Compatible with ZombieBuddy / Viewpoint** (game RAM only, the helper is not started; suggested when ZombieBuddy is found). With ZombieBuddy: try 1 first; if the game closes right after Play, run it again and pick 2. If Windows shows "Windows protected your PC", click *More info* then *Run anyway*. Only download it from this page or the server's Discord.

The installer copies two files to `%LOCALAPPDATA%\CookieSlicer`, sets the game's Steam launch option (Steam's config is backed up first), adds the mod to the main-menu mod list and sets the game's RAM. It changes no game file. The helper sends nothing anywhere; its numbers stay in `Zomboid\Lua\CookieSlicer_*.txt`. Option 2 undoes all of it.
