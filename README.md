# mod_pjz

ม็อด Project Zomboid Build 42 ของ AKA ส่วนใหญ่ทำมาสำหรับเซิฟ **Cookie Cheetah** (dedicated server, PVE)

| โฟลเดอร์ | มีอะไร |
|---|---|
| [`cookie/`](cookie) | ม็อดของเซิฟ Cookie Cheetah (Express, Helper, Mission, Quest, Pack, Server Patch, Watch, Car Skins) + `tools/` สคริปต์เช็คม็อดของแอดมิน |
| [`optimizer/`](optimizer) | **Cookie Slicer**: ตัวช่วยให้เกมลื่น + Shader ([วิธีลงสำหรับผู้เล่น](optimizer)) และ Cookie Slicer ฝั่งเซิฟ |
| [`other/`](other) | ม็อดอื่นๆ (AKA, HF และงานอื่น) |

> [!WARNING]
> **โค้ดในนี้เปิดให้ดูเพื่อความโปร่งใส ไม่ได้ทำมาให้นำไปใช้ต่อ**
> ม็อดใน `cookie/` และ `optimizer/` ทำมาสำหรับเซิฟ Cookie Cheetah โดยเฉพาะ ผูกกับเวอร์ชันเกม (Build 42.22.2) รายการม็อด และค่าของเซิฟเรา
> บางตัวแก้ม็อดอื่นหรือแก้การทำงานของตัวเกมโดยตรง เอาไปใช้ที่อื่นหรือดัดแปลงแล้วอาจทำให้เซิฟ/เซฟพังแบบไม่รู้ตัว
> ไม่มีการรับประกันความเข้ากันได้ และไม่มีซัพพอร์ตนอกเซิฟ Cookie Cheetah
> รายละเอียดเหตุผลของ Cookie Slicer อยู่ที่ [optimizer/README.md](optimizer#ทำไมไม่เหมาะเอาไปใช้ที่อื่นหรือดัดแปลง)

## English

Project Zomboid Build 42 mods by AKA, mostly made for the **Cookie Cheetah** dedicated PVE server. The code is public for transparency, not for reuse: the mods in `cookie/` and `optimizer/` are tied to the game build (42.22.2), our mod list and server settings; some patch other mods or change the game itself, and may silently break a server or its saves elsewhere. No compatibility promise, no support outside Cookie Cheetah.
