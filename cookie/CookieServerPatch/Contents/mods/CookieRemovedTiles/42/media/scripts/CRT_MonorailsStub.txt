/*
================================================================
  Cookie - Removed Mod Tiles : Monorails entity stubs
  Written for CookieCheetah.

  Monorails (3814657376, mod id Monorails) was removed on
  11 Nov 2026. The save's WorldDictionary (SpriteConfigs) lists
  37 of its track/station entity scripts, and a client refuses
  to load the world when one of them is missing.

  These stubs keep those names alive with the same pictures:
  - only the SpriteConfig faces (same sprite names), no
    CraftRecipe (not in the build menu), no UI, no Lua callbacks
  - the sprites come from Monorails' own tile file, kept in
    this mod with its tiledef number (6213), see SOURCES.txt
  - track already turned into plain objects by CookieServerPatch
    (monorails-plain) keeps its picture through the same tiles

  NEVER enable together with Monorails (same entity names and
  tile number). If Monorails is ever put back, delete this file
  and its tiledef/pack lines from mod.info first.
================================================================
*/
